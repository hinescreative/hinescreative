# Wes Hines · Hines Creative

I build the systems that small businesses run on, based in Chicago. Most clients are home-service trades: plumbing, HVAC, septic, wildlife control. A website is usually where the work starts. The real job is everything behind it.

## What I build for businesses

- **CRM and GoHighLevel automation.** Pipelines, missed-call text-back, booking, reminders and follow-up that runs while the crew is on the job.
- **Field-service integrations.** HouseCall Pro, CompanyCam and call-answering AI wired into the CRM, so finished jobs move themselves and nobody types the same thing twice.
- **AI agents.** Intake agents that collect the job details and pass pricing, and anything they're unsure of, to a person.
- **Reporting.** Weekly client digests built from live API data (CRM, field service, QuickBooks, Google), with every number traceable to its source.
- **Ads and local presence.** Google Ads, Google Business Profile and lead-source tracking.
- **Websites.** Fast static sites on Cloudflare, with the call, form and booking path wired into follow-up.

## How I work

I run my own fleet of AI agents across five machines. They coordinate through a shared peer network, a task board and a transcript search, and they build, check and ship work. Most of what's here is tooling for that fleet.

- [`claude-peers-mcp`](https://github.com/hinescreative/claude-peers-mcp): peer discovery and messaging between Claude Code sessions across machines.
- Contributions to [T3 Code](https://github.com/pingdotgg/t3code), the agent workspace the fleet runs in.
